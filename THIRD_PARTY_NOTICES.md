# Third-party software

The original project materials are covered by the proprietary rights notice in
`LICENSE`. The software dependencies retain their own licenses and permissions.
The project's proprietary notice does not withdraw those third-party rights.

Runtime dependencies are Next.js, React, React DOM, Three.js, and Lucide React.
Build dependencies are TypeScript, Tailwind CSS, its PostCSS plugin, and the
TypeScript declaration packages identified in `package.json`. Exact dependency
resolutions are recorded in `pnpm-lock.yaml`.

These packages are installed separately; their source code is not bundled in
this ZIP. Consult the license files supplied with each installed package. If
you redistribute compiled dependency code, preserve the notices required by
those dependencies.

Unused Sites hosting helpers, the vendored shadcn stylesheet, and unused
template components have been removed from this clean export along with their
component-specific notice files. No third-party license has been replaced
with the project's proprietary notice.
